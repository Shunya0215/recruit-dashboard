# 汎用採用広告ダッシュボード

`Rawデータサンプル` と同じ形式の3CSVをドラッグすると、顧客向けPDFにできる分析画面です。

## 使い方

1. `index.html` をブラウザで開きます。
2. 以下の3CSVをまとめてドラッグします。
   - `日別`
   - `CP × 日別`
   - `Job × 日別`
3. 左サイドバーで、期間、CP、職種、雇用形態、給与、エリア、ステータスを絞り込みます。
4. 右側のレポート画面で見たい状態を作ります。
5. `PDF作成` を押して、ブラウザの印刷画面からPDF保存します。

`サンプル読込` は、同梱している `Rawデータサンプル` の内容を読み込む確認用ボタンです。
完成までは表示確認用として残します。

## 見られる内容

- KPI: 費用、応募数、応募単価、クリック率、応募率、求人数
- 比較: 前期間比、前年同期間、予算比、目標CPA比
- 推移: 月次、週次、日次
- 内訳: CP別、求人別、職種別、給与タイプ別、給与帯別、市区町村別、企業・拠点別
- 住所で地域検索: サイドバーのボタンから開き、住所・市区町村から人口、性別、10歳刻み年齢層、有効求人倍率を表示
- 求人×地域: CSV内の求人ごとに、求人地域の人口・10歳刻み年齢層・有効求人倍率を表示
- ターゲット分析: 求人ごとにターゲット年齢・性別・通勤距離を指定し、2026推計の母集団、採用難易度、年齢×性別ヒートマップ、近隣比較を表示
- Google Maps: `config.js` にAPIキーを設定すると地域の地図を表示
- e-Stat: `config.js` にe-StatアプリケーションIDを設定すると、シフト稼働ポテンシャルの層別人数を就業構造基本調査の地域別実数で表示
- PDF: 表紙、総評、KPI、推移、CP別、求人別、給与・職種・エリア分析
- 画面: 左サイドバー操作、右側レポート表示

## メモ

- 月予算は `CP設定金額` から推定します。
- 顧客名は `advertiser_name` または `企業名` から推定します。
- 目標CPAは任意入力です。
- PDFは「現在の絞り込み状態」を反映します。
- Google Mapsを表示する場合は、Google Cloud側で Maps JavaScript API と Geocoding API を有効化し、HTTPリファラー制限をかけたキーを `config.js` に設定します。
- 就業構造基本調査を使う場合は、e-StatのアプリケーションIDを取得し、`config.js` の `window.ESTAT_APP_ID` に設定します。
- Google Mapsは `index.html` の直接起動ではなく、`http://127.0.0.1:8765/index.html` で開いてください。ローカルサーバーは `python3 -m http.server 8765 --bind 127.0.0.1` で起動できます。
- 求人×地域では、個別求人に加えて「全求人（アカウント単位）」で勤務地エリアを横断表示できます。
